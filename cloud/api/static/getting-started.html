Getting started with Faultline Cloud

Faultline does not just track runs — it helps you resume failed training jobs. Log metrics and checkpoints from any script; use the Recovery panel after a crash.

1. Start the API

pip install fastapi uvicorn pydantic python-multipart
uvicorn cloud.api.app:app --reload --port 8080

2. Install the SDK

pip install faultline-sdk

export FAULTLINE_API_KEY=fl_...    # from your dashboard → Account
export FAULTLINE_API_URL=https://your-api.example.com

import faultline in Python — the PyPI install name is faultline-sdk. Local dev from this repo: pip install -e sdk or PYTHONPATH=sdk. Dev API key (seeded on startup): fl_dev_local

3. Log from your script

faultline.start() · run.log() · run.save() · run.restore_latest() 

import faultline

run = faultline.start(
    "my-run",
    project="my-project",
    api_key="fl_dev_local",
    base_url="http://127.0.0.1:8080",
)

step = run.restore_latest(model=model, optimizer=optimizer)

for step in range(step, 100):
    run.log(loss=0.5, accuracy=0.9)  # step auto-increments
    if step % 10 == 0:
        run.save(model=model, optimizer=optimizer, step=step)

run.complete()

Open /dashboard to chart metrics and download checkpoints. Training runs on your machine; the cloud API only stores what you send it.

Try the longer demo (~20s, live-updating charts):

python sdk/examples/cloud_pytorch_easy.py --steps 180 --step-delay 0.12

After a crash

recovery = run.recovery()
run.print_resume_instructions(recovery)
step = run.restore_latest(model=model, optimizer=optimizer)

Or open /dashboard → select the run → Crash-to-resume.

Demo: python sdk/examples/cloud_failure_recovery_demo.py

HPC / Slurm recovery

run.register_slurm_script("train.slurm")

# If the job dies:
# Dashboard → Recovery → Resume Run
# Or: run.resume()

Faultline requeues via sbatch (when configured). Your training script should call run.restore_latest(model=..., optimizer=...) on startup. No Kubernetes, no auto-retry daemon — manual or API-triggered relaunch only.

  1. pip install faultline-sdk on the cluster login node
  2. Set FAULTLINE_API_KEY and base_url
  3. faultline.start() · run.log() · run.save()
  4. Register launch: run.register_launch_command([...]) or register_slurm_script(...)
  5. After crash: dashboard Resume Run or run.resume()
Advanced usage

Explicit init mode

run = faultline.init(
    project="my-project",
    run_name="my-run",
    mode="cloud",
    api_key="fl_dev_local",
    base_url="http://127.0.0.1:8080",
)
run.log_metrics({"loss": 0.5}, step=10)

Raw checkpoint API

run.checkpoint({"model_state": ...}, step=step)
state = run.load_latest_checkpoint_or_none()

Warning: checkpoints use Python pickle — only load checkpoints you created yourself.

PyTorch helper

from faultline.integrations.pytorch import watch_training

run, cb, start_step = watch_training(
    model, optimizer,
    project="my-project",
    run_name="my-run",
    api_key="fl_dev_local",
)
cb.on_step_end(step, loss=0.5)
