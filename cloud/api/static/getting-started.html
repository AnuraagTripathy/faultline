Getting started with Faultline Cloud

Log metrics and checkpoints from any training script with a few lines of Python.

1. Start the API

pip install fastapi uvicorn pydantic python-multipart
uvicorn cloud.api.app:app --reload --port 8080

2. Install the SDK

pip install -e sdk
# or from repo root: set PYTHONPATH=sdk

Dev API key (seeded on startup): fl_dev_local

3. Log from your script

faultline.start() · run.log() · run.save() · run.restore_latest() 

import faultline

run = faultline.start(
    "my-run",
    project="my-project",
    api_key="fl_dev_local",
    base_url="http://127.0.0.1:8080",
)

step = run.restore_latest(model=model, optimizer=optimizer)

for step in range(step, 100):
    run.log(loss=0.5, accuracy=0.9)  # step auto-increments
    if step % 10 == 0:
        run.save(model=model, optimizer=optimizer, step=step)

run.complete()

Open /dashboard to chart metrics and download checkpoints. Training runs on your machine; the cloud API only stores what you send it.

Try the longer demo (~20s, live-updating charts):

python sdk/examples/cloud_pytorch_easy.py --steps 180 --step-delay 0.12
Advanced usage

Explicit init mode

run = faultline.init(
    project="my-project",
    run_name="my-run",
    mode="cloud",
    api_key="fl_dev_local",
    base_url="http://127.0.0.1:8080",
)
run.log_metrics({"loss": 0.5}, step=10)

Raw checkpoint API

run.checkpoint({"model_state": ...}, step=step)
state = run.load_latest_checkpoint_or_none()

Warning: checkpoints use Python pickle — only load checkpoints you created yourself.

PyTorch helper

from faultline.integrations.pytorch import watch_training

run, cb, start_step = watch_training(
    model, optimizer,
    project="my-project",
    run_name="my-run",
    api_key="fl_dev_local",
)
cb.on_step_end(step, loss=0.5)
