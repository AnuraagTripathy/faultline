Monitor and recover ML training jobs from anywhere

Long-running training fails on laptops, clusters, and cloud VMs. Faultline Cloud tracks metrics, checkpoints, and run status so you can see progress and restore after interruptions.

View Dashboard Getting Started

The problem

Training runs for hours or days. Nodes preempt, disks fill, processes crash. Without durable metrics and checkpoints you lose visibility and progress.

The solution

Stream metrics and events from your script. Upload checkpoints to the cloud API. Use the dashboard to inspect runs and download the latest state.

Dev limitations

API keys are plaintext dev tokens (e.g. fl_dev_local). Storage is local SQLite + filesystem under cloud/data/. No Stripe, no login UI yet. Production would use object storage and real auth.
