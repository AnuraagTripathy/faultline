Local dev preview · Version 17.2

Faultline does not just track runs — it helps you resume failed training

When a laptop, HPC node, or cloud VM dies mid-training, Faultline shows your latest checkpoint, lost steps, checkpoint health, and copy-paste resume code. Less digging through logs than generic experiment trackers.

View Dashboard Getting Started

The problem

Training runs for hours or days. Nodes preempt, disks fill, processes crash. Without durable metrics and checkpoints you lose visibility and progress.

Crash-to-resume

The Recovery panel shows checkpoint step vs last logged step, estimated lost work, health checks, and resume + Slurm snippets. Call run.recovery() from Python after a failure.

Dev limitations

API keys are plaintext dev tokens (e.g. fl_dev_local). Storage is local SQLite + filesystem under cloud/data/. No Stripe, no login UI yet. Production would use object storage and real auth.
